# Security

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue.

- **Preferred:** GitHub private vulnerability reporting on this repository
  (Security tab, "Report a vulnerability").
- **Email:** security@guvnacloud.com

We aim to acknowledge reports within 3 working days and keep you updated
until the issue is fixed.

## Supported versions

Security fixes go into the latest release. Pin the action to a full commit
SHA and let Dependabot propose updates.
